## Reading (claim labels per CLAUDE.md)

- **Verified** (this run, toy model): the shipped curve's shape depends on an arbitrary unit choice for R — its edge-on weight and peak position move under a pure rescaling.
  A feature that moves under a pure unit change is not a property of the physics.
- **Verified** (this run): with a dimensionless R row the weight peaks at edge-on (w≈1) for every seed, on both phase grids.
  The log-R curve is not strictly monotone: the table lists the isolated decreases.
  Their cause was not isolated in this run; a likely one is a near-singular sky draw dominating the mean κ at that ι (inferred, not checked).
- **Verified** (Control 3): on an exactly periodic phase grid κ + 1/κ = (p² + q² + 4)/(2|p|) with p = 2·(N/2)·r·g'(β)·(row scale) and q = 2 k1 k2/(k1² cos²β + k2² sin²β), reproducing the numerical κ with max relative error 1.3e-05.
  p carries the raw-R factor N r / 2, which is why the R scale sets the curve's shape; at face-on g is constant, p = 0 and κ diverges.
- **Inferred**: the edge-on dip in `derive_w_iota` is an artifact of the metric, not a real re-degradation near edge-on.
- **Not shown**: that the true weight is monotonic.
  The log-R curve is much more edge-concentrated than sin²ι, and other dimensionless normalisations were not compared, so this run does not pick a replacement weight.
- **Scope limits**: toy detector model only, one fixed reference (φc, ψ), no check against the real generator.
  Training used sin²ι throughout, so no trained model depends on this result.
