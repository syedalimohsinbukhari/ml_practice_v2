**⚠ Central question not yet answered — mechanically confirmed UNINTERPRETABLE (2026-09-15), still UNINTERPRETABLE after both the λ=0.05 (2026-09-15) and λ=0.10 (2026-09-16) retunes, and the λ-retune line of attack is now closed.** `config_poc.yaml`'s combo_A/combo_B circular loss stays flat (~0.98–1.01) across all 80 epochs — nearly identical to the original's wrong-formula result (0.9989/0.9913 vs. this run's 0.9999/0.9895). `diagnostic_logvar_gate.py` ran the Step 0 std_ratio gate (thresholds from `preregistration_lam_retune.md`) against it: **FAILS on both heads.** (Correction: the earlier "weight_combo_A/B still climbing" read was checked mechanically and does not hold up — it plateaus; see `NOTES.md`'s dated correction.) The λ=0.10 retune (last committed fallback) FAILED 3 of 4 readings; the one reading that passed (`lam010_retune_b`/coa_phase) turned out on scatter-plot inspection to be a **std_ratio false-positive** — the predicted-vs-true plot shows a flat, mode-collapsed constant output (two bands offset by 2π, no per-sample tracking), present from epoch 5 through epoch 80, not real learning that a summary statistic alone would have missed catching. **Verdict of record, per the preregistration's own decision table: "λ alone insufficient for this architecture/head, post-formula-fix."** This is a negative result about the retune mechanism, not the corrected-formula degeneracy hypothesis — the central question remains formally unanswered under this line of attack. See `NOTES.md`'s 2026-09-16 entries for full detail, including the scatter-plot correction.

**Methodology gap surfaced by this round, flagged for future diagnostic work (not yet actioned):** the Step 0 std_ratio gate can both false-positive (a collapsed/constant predictor with population-level variance that happens to match the true population) and, in the opposite direction, undersell a partially-learned but degenerate/ambiguous output (ψ's two-branch structure, each branch individually tracking true value, still reads as a variance-deficient FAIL). A scatter-plot check against `runs/<name>/<ts>/scatter/epoch_*.png` should be a required companion to any future std_ratio-only gate, not an optional/manual afterthought.
